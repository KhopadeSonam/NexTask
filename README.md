✨ What is NexTask?

NexTask is a lightweight productivity application designed around one simple idea:

Know what needs to be done, decide what matters most, and get it done.

Instead of overwhelming users with unnecessary complexity, NexTask focuses on the essentials of task management — creating tasks, assigning priorities, organizing them into categories, and seeing completion progress at a glance.

🎯 Core Features

Feature

Description

➕ Create Tasks

Quickly add new tasks from the main interface

🎯 Priority Management

Assign priority levels such as Low, Medium, or High

🗂️ Task Categories

Organize tasks into General, Work, Personal, and more

✅ Task Completion

Mark tasks as completed and keep track of progress

📊 Progress Tracking

See how many tasks are completed compared to total tasks

🧩 Clean UI

Simple interface designed to keep the user's focus on their work

🚀 Getting Started

Prerequisites

Make sure you have the following installed:

Node.js

npm

Git

1. Clone the repository

git clone https://github.com/KhopadeSonam/NexTask.git

2. Open the project

cd NexTask

3. Install dependencies

npm install

4. Start the development server

npm run dev

The application will be available at the local URL displayed in your terminal.

5. Create a production build

npm run build
